## 原件与清理

受测代码和输入先存Git commit/blob及runtimebyte双hash，实际测试argv/nativeexit/runtime/数量/skip/首败／proxy失响应／DB锁观察／providereffect计数／模型tool_result逐项保存；公开消息与可见rationale可保，hidden思维不可保。原stdout/stderr经过准确脱敏与thinking事件过滤，保存过滤规则、原byte可得与不可得边界；不拿文本副本哈希冒脱敏前原件。

Stop清理先禁模型/工具/steering，独立有界finally持原E Token Stop_ACK；记录Lease释放、残留／unknown，强杀不假称资源干净。保全后只关本人闲置listener／PID、按准确ID删本人owned闲置container/volume/network。共享image、store、旧证据、活动引用、当前恢复目录、G1D0C3已拒目标全部保留，不globalprune。

Windows递归前逐path核resolved绝对目标仍在指定workspace内、无link外跳、无活动引用、保全依据齐全；保留原nativeexit/实际结果。自动审批拒绝即停该目标，不能Force/ACL/属性变更、换工具、拆分、移走、父删绕过。已合worktree仍须actualmain／保全齐／无引用才另行清理；本轮不清工作树。
