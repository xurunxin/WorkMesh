# 现有领域功能与 Agent 使用链覆盖矩阵

基准为sources.md的精确main。这里按使用闭环分组，逐REST operation的角色、路径、OpenAPI行、schema参数/返回和SDK静态定位见[完整索引](operation-index.md)。以下“已有”只指读取到实现与合同，不指本轮运行通过；“缺入口”只指当前适配层缺口，不指领域不存在。

## 角色、模式与现行实现

- **C：Coordination Agent**。Connection绑定单Team和principal Human，使用 `X-WorkMesh-Installation-Token`；服务端派生短Coordination Session。普通规划可用，执行写需接单后精确Session bridge。依据：`apps/api/src/agent-connections.ts`、`apps/mcp/src/http.ts`、ADR0043/0046/0047–0049。
- **E：执行Agent**。精确Session Bearer、有效Delegation、实时definition/Team/capability交集和资源范围。依据：`apps/api/src/agent/guard.ts`、`apps/api/src/authz/authorize.ts`。拥有Lease不能替代上述前提。
- **R：外部Runner服务协议**。工作台assignment/attempt credential/start/status/settle等属于执行器内部控制，不作为模型通用管理工具。依据：`apps/agent-runner/src/run-session.ts`、`apps/api/src/workbench-runner.ts`、ADR0068。
- **H：Human/管理员**。保留API/policy指定动作；Agent可请求或读取允许的批准信息，不能自己决定。依据：`packages/contracts/src/route-policy.ts`的 `humanOnlyOperations` / `workspaceAdminOperations`及各领域命令。

`apps/mcp/src/index.ts`按mode及coordination注册工具，未逐工具以live manifest过滤所有MCP注册。`apps/agent-runner/src/workmesh-tools.ts:125`以manifest支持和能力交集过滤其手写工具子集；不能因此声明它涵盖manifest所有操作。复合工具、按provider kind的权限、运行协议和Human-only工具需要单独审计。

## 完整错误与恢复信息要求

所有新适配须保留实际API `error.code/message/details/correlationId`；客户端本地schema错误用 `MCP_INPUT_INVALID`及字段issues，不伪造服务端trace。仅在有真实details时返回currentRevision、期限/holder/actionId等；缺省不可猜。下表是未来测试期待的恢复行为，不是当前每个工具已做到的承诺。

| 情形 / 现有机器码或待设计码 | Agent应收到并如何恢复 | 对应批次 |
| --- | --- | --- |
| `FORBIDDEN`、`CAPABILITY_DENIED`、`RESOURCE_SCOPE_DENIED`、`NOT_FOUND`、`DELEGATION_NOT_ACTIVE`、Connection/Token revoked或expired | 保留拒绝阶段/相关ID的安全details；终止受影响命令，重读当前身份与授权允许的上下文或请求H修正。NOT_FOUND不泄露跨Team存在性；不自动重试或换凭据 | 全部 |
| `SESSION_STOPPED` / `INVALID_SESSION_TRANSITION` | 停止普通写和外发；通过允许的专用stopAck给cleanupSummary/residualRisks，重复保持原事实；非法转换读取Session后报告，不自恢复stop状态 | M1/M5 |
| `REVISION_CONFLICT` / `PLAN_REVISION_CONFLICT` / `IF_MATCH_REQUIRED` | 返回currentRevision（若有）、当前资源/版本读取入口；重新读再明确合并意图，正文改变用新key，整Plan不覆盖新版本 | 全部写 |
| `IDEMPOTENCY_KEY_REUSED`、网络/响应丢失、`IDEMPOTENCY_REPLAY_EXPIRED` | 同逻辑调用持久保留同key/body；改体冲突禁止重试旧身份；已提交未知结果按ID/事件查询，窗口外先对账，不盲建第二条 | 全部写 |
| `LEASE_REQUIRED` / `LEASE_CONFLICT` / `LEASE_EXPIRED` | 返回安全holder/session/resource/expiry；取/等待/维护当前租约，失效停止受保护动作；不强制抢占、Lease不恢复授权 | M1/M3 |
| `APPROVAL_REQUIRED` / 未批准、过期、payload mismatch、head变化 | 使用现有request_approval，返回准确action/payloadHash和读取入口，等待H或已授权策略；旧批准不能消费新payload/head；merge批准只由Worker消费 | M1/M3 |
| `FEATURE_DISABLED`、profile unsupported、provider不支持 | manifest/部署info列支持层级与feature；停止该可选链，提供正确角色配置入口；不声明安装工具即可启用。provider错误码沿实际API，不发明当前已实现统一码 | M0/M4/M5 |
| `CURSOR_EXPIRED` / cursor invalid / scan limit | 保留服务端resync信息；重建授权投影，event decimal与collection opaque不互换。列表输出过大需返回nextCursor/可继续读取引用，不因truncated丢剩余页 | M0/M2/M5 |
| 已提交provider action pending/claimed/completed/failed/dead、外部结果unknown | 返回原actionId/准确目标/终态/安全错误及下一只读步骤。exact action查询合同待M3新增；unknown不自动重发不可逆外部请求 | M3 |
| `COMPLETION_EVIDENCE_REQUIRED` / `COMPLETION_PLAN_INCOMPLETE` / `REVIEW_COMPLETION_EVIDENCE_REQUIRED` | 返回尚未满足的证据/步骤/准确blockerSessionIds；required子failed/canceled/stale/active仍阻塞。reviewer缺本人Room review_result或code_review须补齐，structured review不替代，noArtifactReason不豁免reviewer；保持真实状态，不拿Turn回答当完成 | M1/M2/M3/M5 |
| `STALE_PLAN_VERSION` / `PLAN_STEP_IDENTITY_MISSING` / `CHILD_SESSION_LIMIT` / `PLAN_STEP_CHILD_SESSION_LIMIT` / `CHILD_BUDGET_EXCEEDED` / `AGENT_CONCURRENCY_LIMIT` | 读取父当前Plan/version/stable step及安全限额details；改意图才用新key。等待真实capacity/预算释放，或请H按原权限处理；不能改required=false、换step/Agent/key绕限额。review_shared与exclusive冲突沿LEASE_CONFLICT处理 | M2 |
| 本地超限/超时/取消、事务失败、outbox重放 | 返回有界安全错误，不泄露凭据/body；区分未发送与可能已提交。事务回滚零领域状态/event/outbox，重复job不重复事实；确认查询不修改领域 | 全部 |

缺口本身不能赋予权限。后续批次若需新REST/error/事件，先更新OpenAPI和Zod，按ADR触发规则形成相应决策；保持领域命令在同事务写state/event/outbox、外部调用提交后执行。当前Human-only查询的身份解析也要避免先创建Coordination Session等副作用，拒绝账本例外沿ADR0028保留。
