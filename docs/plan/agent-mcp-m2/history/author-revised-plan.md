## 产品变更

- **`OPENAPI.yaml`、`packages/contracts/src/child-session-contracts.ts`、`index.ts`、`route-policy.ts`**：统一两种创建的共享输入／typed 输出及本批协作 DTO；`ReviewDelegationInput` 新增可选 `budget: Record<string, number>`，Zod 校验 finite／非负。新增 `childAgentSessionResponseSchema`，扩展现有 Session schema，必含 `parent_session_id`、`plan_step_version_id`、`required_for_parent`、`inherited_budget`、`max_child_sessions`；`budget`／`inherited_budget` 使用数字 record 保留原维度，创建响应使用 `.passthrough()` 保留现有额外字段，不能经普通 `agentSessionResponseSchema` 剥离。review 输出使用 `{session: childAgentSessionResponseSchema, lease: leaseResponseSchema}`，保留原 wrapper 字段。新增 `GET /api/v1/agent-sessions/{id}/children`，`operationId=listAgentSessionChildren`。支持 `childSessionId` 精确过滤和签名分页，返回 child ID、父 ID、required、state／revision、原 Plan/version/stable step 绑定及经授权过滤的结果 Artifact ID。保留创建接口无 `If-Match`、现有 revisioned 写入规则及原消费者字段。
- **`apps/api/src/agent/child-session-status.ts`、`agent/routes.ts`**：实现并注册投影，复用 `liveSessionReadPredicate` 和 `Paginator`，在返回数据的查询中重验准确父 E 凭据、Delegation、principal、Team grant、资源及父子创建绑定。只读直接子 Session，包含旧 Plan 绑定和子终态；父终态、撤权、错父／Team／child 拒绝。查询不创建业务事实，不返回 token、prompt 或其他子资源内容。
- **`apps/api/src/agent/child-session-policy.ts`、`collaboration/routes.ts`**：从 `createChild` 提取共享准入，供 `createReview` 复用；沿 `lockCollaborationSessionTargets` 的既有锁序校验当前 Plan、稳定 step、父既有总量上限及父／step 活跃限额、三方能力、目标并发和累计 reservation。保留现行 DB trigger 的父累计总量保障，子终态不释放父总量槽位；step 活跃限额按稳定 ID 跨 Plan 版本统计。reviewer 复用 `inheritChildBudget(parent.budget, body.budget ?? {})`，将所得有效预算写入 `budget`／`inherited_budget` 并按同值 reservation；复用 `reserveChildBudget` 检查各维累计占用，保持外部 `CHILD_BUDGET_EXCEEDED` 拒绝码。显式缩减超过父上限、负数／非有限值或剩余额度不足均拒；不自动释放既有 reservation，不自动按余额改写调用意图。Session、Delegation、reservation、review_shared Lease、prompt、交付和 event／outbox 同事务提交，继续由 `provisionNewSessionDelivery` 受控启动。使用现有表，无新增迁移或事件类型。
