## 目标
每个接入失败现在只是一个裸错误码。指令让 agent「停下并报告错误码」是对的，但对恢复毫无帮助。补上「自己能做什么」与「需要人做什么」。

## 背景与证据（已核实，file:line）
- 错误码定义位置：`apps/api/src/agent-connections.ts` 兑换处理链
- 类型不匹配会累计 attempts 并在 8 次锁定：同文件 `:521`、`:524-525`、`:561-562`；且**只**在已知身份不匹配时累计，随机错误码不会消耗合法配对对的预算
- 限流维度（来源：P1 冻结提交 660c74a6247544ffac64e7ef8f968d1025b2a668 的主计划第7/8条）：endpoint、subject-client 桶和失败退避均按 `operationId` 隔离；只有 socket peer/client IP 桶共享（`apps/api/src/auth-rate-limit/limiter.ts:122-145,154-159`；`apps/api/src/auth-rate-limit/inventory.ts:36-37`）。旧卡「失败退避共享」表述已撤换。

## 交付物
所有接入错误携带 `next_action`（客户端自己能做什么）与 `human_action`（需要人做的唯一一件事，措辞可直接粘贴）。客户端类型不匹配时额外返回部署支持的类型列表。
