## 目标与范围

1. 在外部 Runner 建立每次运行隔离的仓库/worktree、输入快照、环境和产物目录；租约只协调资源，不授予仓库写权限。
2. 规划/审查是强制只读执行配置；实施按委派授予文件/命令/网络能力，运行不加载宿主全局工具或凭据。隔离方案先 ADR 定义威胁边界与受支持 OS，不能把普通工作目录称为沙箱。
3. 保存 base/head SHA、工作区检查点、运行关联和恢复资格；迟到完成受 fence/revision/Stop 约束；恢复由明确检查点或关联 successor 承担，不承诺任意外部 CLI 原地续跑。
4. Git 提交/推送作为受控外部效果，只有 durable intent 提交后发生；失败保留本地产物和可重放身份，不因本地 commit 就显示远端交付成功。
