## 采集和停止条件

复用现有匿名 RAM 捕获：只处理已登记准确 Node 身份；core 上限 512 MiB、无 swap、handler 最多 90 秒、GDB 最多 60 秒。准备只读身份轮询最多每秒一次、最多 90 次；不在请求前读取完整可执行文件。仅保存阶段、时钟来源、关联摘要、退出事件和有界公开运行时帧。

保持现有 `core_metadata.py` 的隐私边界，不输出寄存器、堆／对象内容、原始地址、映射路径、参数、私有栈或原始 core。若核心位置不在受信 Node 模块，先记 other-or-unmapped，不能猜另一模块身份。需扩展模块解析时只限已核公开二进制及摘要，新增采集范围先裁定，不临时放宽过滤。

完整输入身份需同时保镜像闭包和运行中的 Node 身份；有完整镜像差异仍不能证明故障不适用最终环境。只有定位到实际致因差异，并以旧失败／最终输入修复证明其不再适用，才可提出闭合。最终正式验收继续使用已批准的完整 guest，不通过改口排除 TCG 来取绿。

GDB／固件等工具必须来自已有准确工具闭包。缺工具、版本或摘要不符，直接保存缺口，不安装新宿主依赖、申请设备或换版本。捕获受拒、超限、迟注册、首败或目标请求完成都触发停止；更早的业务失败优先保全。自然重启后的新 PID 不自动重新注册，不重试请求。
