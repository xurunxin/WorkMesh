# C3 规划交接包

[完整中文计划](../c3-model-presets.md) 是平台已保存正文的逐字节副本，不是 doc 链接摘要。[当前规格全文](spec.md) 来自本轮 todos 读取；[来源与哈希](source.json) 绑定当前任务、当前保存计划 ID、正文内容、文件字节和输入提交。

## 本轮授权与停点

本轮仅提交 docs/plan 下的规划、来源、核对和验证材料，不开始产品实现，不改 API、契约、部署或测试代码。产品方案不变，本轮不调用 edit_plan，不生成新计划；将原 currentID 实读绑定，避免哈希自引用导致循环存新。

Chief 反馈的原文在 [conversation-read.json](conversation-read.json)，其中明确授权文档前置，要求完成后停在 confirm，由 Chief 安排独审再确认。本包完成不代表产品 DoD、独审或 Chief 确认已完成，也不冒称平台阶段已被本 agent 修改。

## 审核入口

- [完整中文计划](../c3-model-presets.md)：后续实现范围、逐文件变化和验证步骤。
- [当前规格全文](spec.md)：已同步增加 OpenAI，已撤回“通常可达/兼容”的背景泛断言；保留历史来源说明。
- [source.json](source.json)：平台正文和当前 ID 的来源、null 版本、哈希及本轮仓库基点；哈希政策区分正文字符串与文件字节。
- [官方资料核对](official-source-review.md)、[官方字段记录](official-sources.json)：九家均有记录，缺口如实标出。
- [测试责任与原验收](test-coverage.json)：保留 R1 原测试、DoD 和九类适用性，新增用例仍是计划，未运行。
- [文档验证](validation.json)：仅本轮文档检查实际结果；产品检查明确未运行。

## 定向独审清单

只读目录无 CRUD/表/写事务；部署完整替换及禁用优先；normalizeLlmBaseUrl 的 HTTPS、凭据、路径、私有主机及管理员/allowlist 校验仍执行；选择只填字段，连接和模型均显式提交；实际连接 POST/PATCH 零模型服务出站；公开目录与功能关闭路由的可见性、错误和政策清单一致；每条来源、地区、日期和确认方式可追溯，不把资料核对当兼容性。

公开读取会暴露目录内的部署配置字段，独审需明确核对这一点；现有连接和秘密仍遵循原鉴权流程。鉴权拒绝审计是既有 Accepted 决策，目录的只读或零模型服务出站不等于失败请求全数据库零写入。

## 输入差异与后续门禁

本轮最新 main 已包含 D1a，当前会话分支基点尚未包含该增量；本轮只提交文档，没有整合产品提交。相关连接、配置、契约和 C3 规格路径经实际 diff 核对无重叠。进入产品实施前重新读取 main 与任务，正常整合最新已落地增量，核对共享主题/测试变动及完整必需检查，不能沿用本轮读数冒最新状态。

本批继续采用 Todos＋仓库例外，没有创建或同步真实 WorkMesh Project/WorkItem。本轮成功仅指文档交接可供独审；产品 DoD 和 Chief 放行仍待后续。
