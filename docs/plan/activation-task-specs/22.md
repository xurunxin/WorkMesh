## 交付物与约束
- 列间拖拽与修饰键点选多选，复用现有单项移动适配器。
- 批量逐项提交、显示逐项结果；部分失败保留失败项及恢复入口，成功项不伪装回滚。
- 网络结果未知只重放原请求；409 重新展示当前数据并由人确认，不擅自换幂等键重试。
- 领域写入走既有身份、授权、稳定 Idempotency-Key、revision/If-Match、乐观并发与停机纪律，不增加第二套 mutation API。
- 任何破坏性转换需显式确认；不得实现无确认的拖拽重置。
- 拖卡进对话只修改草稿、插入任务引用，不自动发送；导航、复制链接、插入引用等纯本地操作不发领域 mutation，不要求 mutation 幂等键或 revision。
- 若实现需要全批次原子移动，属于新 ADR/后端范围分歧，必须停下来向用户裁决，不顺手扩展领域契约。
- 使用 G1 纳入受控路径的参考交互材料，保留既有 canonical 导航规则。
