# D1b 阶段保护设计

本文件落实已审计划第 1 步的断言设计，尚未修改 `theme.test.tsx` 或执行界面迁移。
历史 `theme-token-baseline.json` 保持原件；175 条声明、132 消费组、1,476 引用仍描述
D1a 的冻结阶段，不把它们当作 D1b 全部生产消费。补充清单在 `consumer-inventory.json`。

## 保护状态与转换

| 状态 | 必须满足 | 允许变化 |
| --- | --- | --- |
| 文档前置 | 生产 CSS/TS/TSX 与输入 Git blob 内容一致；全部旧声明和值仍保留 | 映射、来源、规格、断言设计 |
| 并存定义 | 新槽完整、来源可核、作用域图无循环/缺失；旧声明不变 | 新定义及暗色同值重绑定、切换边界的新派生公式 |
| 单面迁移 | 仅本面新增使用点已映射；未迁使用点不变；共享使用点隔离 | 本面临时 CSS 分支、作用域及必要专属组件 |
| 全局迁移 | 已验收面和共享/portal 全矩阵复验，证据与评审齐全 | 全局消费与运行时 fallback |
| 统一 | 全部适用行与全局复验批准，统一后回归无意外差异 | 删除临时分支；旧定义继续保留 |
| 清旧 | 全源码及活动夹具旧消费与别名依赖为零，全部评审闭合 | 删除旧 root/dark/compact 与旧 candidate 声明 |
| 最终验收 | 清旧后无退役名称/悬空/循环；明暗与功能、必需检查、独审、合入及 Chief 确认 | 宣告 D1b 完成；后续卡仍单独放行 |

每个状态转换要有对应账本和证据，不能通过删除旧测试、改基线或单改阶段字段放行。
静态扫描只能证明源代码条件，不能代替人工颜色验收。

## 消费身份与阶段账本

未来实现的扫描器需分别解析 CSS 声明和 TS/TSX 表达式，不依赖行号作为身份：

- CSS 身份：文件、at-rule 路径、完整选择器、属性、同属性出现序号、值内 var 出现序号。
- TS/TSX 身份：文件、AST 表达式范围/节点路径、style 属性或字符串位置、值内 var 出现序号。
- 注释忽略；字符串、嵌套 fallback、`setProperty`、运行时 key、生产者和测试夹具不能忽略。
- 每次迁移登记旧消费身份、目标表达式、所属 stage/区域、临时分支及原始源码 hash。
  同一共享选择器/表达式对应多个面时，旧分支继续冻结，新分支按 scope 独立登记。
- 以完整生产扫描为当前集合，D1a 原清单作历史子集交叉核验。未知消费必失败，
  不因新消费不在历史清单就允许遗漏；丢失、错误目标、提前全局替换及重复登记均失败。

`consumer-inventory.json` 当前只做词法取证，含 UTF-8 源码行、字符偏移和前置指纹；
不声称完成 AST 阶段扫描。实现上述扫描器及其负向断言属于前置获准后的产品编码阶段。

## 依赖图与运行时变量

按 root、dark、compact 及主题/密度交叉的实际级联建立声明解析图；将每一个 `var()`，
包括嵌套 fallback 中的引用作为边。检测未知变量、有效级联中的循环、无定义且无允许来源的依赖。
保留三个实例变量：`--wm-status-color`、`--wm-dismissal-depth`、`--wm-overlay-depth`。
前者有 workflow 与 work-item 两个生产者；后两者由 overlay 注册/注销管理。
允许清单必须逐项对应实际未声明依赖，不允许只核对名单中条目。

`--wm-muted` 与 `--wm-text-muted` 仅在显式批准的 secondary 目标合并，重复目标
须检查所有重叠作用域值一致；其他碰撞立即失败。dark 的新槽最终直接持有原暗色值，
不能沿旧别名删除后悬空。dim 不与 tertiary 合并。新增候选退役项不遗漏于旧115槽之外。

继承测试必须用真实浏览器验证：light 根→dark 子树、dark 根→light 子树、compact 子树
及嵌套主题/密度组合；检查实际背景、文字、边框、圆角、渐变、focus-ring 和控制高度。
只检查 custom property 字符串不足以发现父级已解析的公式/别名错误继承。

## 必须实现的负向断言

| 故障输入 | 预期拒绝 |
| --- | --- |
| 任一旧消费仍存在时删定义；别名或 derived 仍依赖旧值 | 缺失定义/清旧先决条件失败 |
| 本面映射缺一项、错误目标、未登记新增引用 | 消费集合与账本不一致 |
| 共享选择器直接替换，未迁兄弟面或 portal 变色 | 区域隔离断言及未迁面截图/计算样式失败 |
| root 定义正确但 dark 别名旧名删除 | dark 依赖解析失败 |
| A→B→A 或 nested fallback 指向未知变量 | 图循环/未知依赖失败 |
| 删运行时生产者或引入第四个未登记实例变量 | 生产者与未声明依赖集合不一致 |
| compact 或嵌套主题继承父级公式 | 控制高度/派生属性 computed style 失败 |
| 矩阵行未评审却进入下一面或清旧 | 阶段门禁失败，不允许自动填人工批准 |
